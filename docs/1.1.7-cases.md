# 1.1.7 用户反馈与验收用例

本轮按 2026-10-21 确认的范围修复，版本号统一为 1.1.7，安卓 versionCode 为 8。

| 原反馈行 | 本轮处理与验收重点 |
| --- | --- |
| 37、39 | 拖动时间轴暂停播放，参考视频保留比例；重复播放、定位、载入均正常。 |
| 38、56 | 固定人数档位合并成输入总人数；3→30→5 必须得到准确人数，原人员站位不变，减少前提示，一步撤销。 |

| 43 | 沿用标准模式的独立队形区间、保持／过渡时长编辑和边界拖动，回归现有交互用例。 |

| 49 | 支持秒数及分:秒.毫秒跳转；无效输入、超长时间、负数、非数字均不得导致崩溃。 |
| 50、52 | 更换媒体无须删除工程，保存重开后仍为新内容；失败不得悄悄保存成旧媒体。 |
| 51 | 沿用左右台下区域，并通过编排与导出回归验证。 |
| 54 | 沿用本机自定义名单与 JSON 导入导出；不增加复杂人员库。 |
| 55 | 安卓增加重做，电脑端保留既有重做；撤销后新增编辑会清空旧的重做分支。 |
| 更新权限 | APK 包含安装权限声明；未授权时打开系统安装来源授权页，返回后可再次发起更新。 |

不新增独立排队形页面、完整剪辑器或复杂人员库。团队名单预设与本机自定义名单继续保留。

自动测试入口包括 Maven 单元测试、JavaFX 界面与真实视频导出测试、安卓 JVM 测试及 `Editing117DeviceTest` 设备测试。实际执行结果记录在本地 `target/qa-1.1.7/`，最终安装包另行执行证书、版本、运行时与文件名单验证。
